# fixtures

테스트와 예시 화면에 쓰는 도안입니다. **모두 이 저장소를 위해 직접 쓴 도안**이고,
구매한 도안이나 다른 사람의 도안에서 가져온 내용은 없습니다.

| 파일 | 내용 |
| --- | --- |
| `practice-hood.ts` | 연습용 후드 워머. 고무단, 단춧구멍, 늘림, 줄임, 감아코, 마커, 길이로 적힌 구간, 코막음까지 기호 10가지를 모두 씁니다 |
| `garter-scarf.ts` | 가터 목도리. 길이로만 적힌 가장 단순한 도안 |
| `practice-ball.ts` | 연습용 코바늘 공. 매직링에서 시작해 나선으로 늘리고 줄이는 짧은뜨기 소품 |
| `practice-scarf.ts` | 연습용 코바늘 목도리. 사슬에서 시작해 한길긴뜨기로 왕복 (시작 사슬, 기둥코) |
| `practice-pouch.ts` | 연습용 코바늘 파우치. 사슬을 둘러 뜨는 타원 바닥, 빼뜨기로 닫는 원형단, 이랑뜨기 |
| `practice-granny.ts` | 연습용 그래니 스퀘어. 사슬 공간에 뜨기, 같은 자리에 더 뜨기, 코로 세는 기둥코 |
| `practice-shell.ts` | 연습용 조개무늬 수세미. 건너뛰기와 한 코에 여러 번 뜨기 |
| `practice-bear.ts` | 연습용 코바늘 곰 인형. 머리, 몸통, 팔 2개, 귀 2개를 따로 뜨는 도안 (조각 여러 개, "2개 만들기") |
| `reading/` | 위 도안을 사람이 읽는 도안처럼 조판한 PDF와, 그 PDF에 대한 LLM 응답 대역. `pnpm fixtures:reading`으로 다시 만듭니다 |
| `expected.ts` | 위 도안을 엔진으로 검산했을 때 나와야 하는 숫자 |

실제 도안(PDF와 그 내용)은 여기에 두지 않습니다. `private/` 폴더에 두면 git에서 제외됩니다.
