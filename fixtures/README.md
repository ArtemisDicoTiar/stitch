# fixtures

테스트와 예시 화면에 쓰는 도안입니다. **모두 이 저장소를 위해 직접 쓴 도안**이고,
구매한 도안이나 다른 사람의 도안에서 가져온 내용은 없습니다.

| 파일 | 내용 |
| --- | --- |
| `practice-hood.ts` | 연습용 후드 워머. 고무단, 단춧구멍, 늘림, 줄임, 감아코, 마커, 길이로 적힌 구간, 코막음까지 기호 10가지를 모두 씁니다 |
| `garter-scarf.ts` | 가터 목도리. 길이로만 적힌 가장 단순한 도안 |
| `expected.ts` | 위 도안을 엔진으로 검산했을 때 나와야 하는 숫자 |

실제 도안(PDF와 그 내용)은 여기에 두지 않습니다. `private/` 폴더에 두면 git에서 제외됩니다.
